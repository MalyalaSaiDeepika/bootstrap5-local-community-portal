# 🏙️ Bootstrap 5 Local Community Event Portal

A fully responsive web application built using **HTML5, CSS3, JavaScript, and Bootstrap 5**.  
This project is created as a frontend development practice exercise to understand Bootstrap components, responsive layout system, and basic interactivity.

---

## 🚀 Project Overview

The **Local Community Event Portal** is a simple web application that allows users to:
- Browse community events
- View event details (location, fee, seats available)
- Register for events using a form
- See dynamic seat updates when registration happens
- Submit feedback about events

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5
- Bootstrap Icons

---

## 📌 Features

### 🎨 UI Features
- Fully responsive layout (mobile, tablet, desktop)
- Bootstrap Grid system (container, row, col)
- Responsive Navbar with collapse menu
- Event cards with images and details
- Sidebar layout using grid system
- Typography utilities (uppercase, lowercase, lead text)
- Visibility utilities (d-none, d-md-block, etc.)
- Buttons, badges, icons, and Bootstrap components

### ⚙️ Functional Features
- Event registration form with validation
- Seat availability dynamically decreases on registration
- Auto-fill event selection when clicking "Register"
- Form validation for empty fields and email check
- Feedback submission system
- Basic search interaction (UI-level functionality)

## ▶️ How to Run This Project

### Method 1 (Recommended)
1. Open project in **VS Code**
2. Install **Live Server extension**
3. Right-click `index.html`
4. Click **Open with Live Server**

### Method 2
- Simply double-click `index.html` and open in browser
